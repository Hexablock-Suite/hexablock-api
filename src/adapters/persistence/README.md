# adapters/persistence

Repository adapters that implement application ports with Drizzle ORM. Imports `src/application`, `src/domain` and `drizzle-orm`; never `src/infrastructure` and never `@nestjs/*`. The infrastructure binds each adapter to Nest and to the `DATABASE` provider in `src/infrastructure/database`. The row mappers and the repositories receive the value of a value object through the helpers of `../received.ts`, for a row field, an SQL filter or the lock key. `LevelRowMapper` restores each `levels` row through `LevelValidators`, so the strategy of the row's `gameId` builds the section, and `receiveJsonOf()` writes the section as the JSON of `docs/level-format.md`. `DrizzleLeaderboardReader` reads only the `progress` and `level_results` tables: it filters and sums, adds no order, and names no table of the user module. `ProgressRowMapper` and `DrizzleLeaderboardReader` build each level result through `buildLevelResult()` of `../built.ts`. A factory that gives a failed `Result` for a stored value is a server fault: `storedValue()` in `stored-value.ts` throws, and `UserRowMapper` throws for a users row (decision 11).

`schema.ts` is the Drizzle schema. It lives here because the repositories query its tables and cannot import `src/infrastructure`. `drizzle-kit` reads it to write the migrations in `drizzle/`, and `src/infrastructure/database/connection.ts` passes it to Drizzle.
