# adapters/http

Nest controllers, request/response DTOs, `HttpErrorFilter` and `JwtAuthGuard` that translate HTTP to use cases. `JwtAuthGuard` calls the `AuthenticateToken` input port, never the `TokenIssuer` port. `ProgressDtoMapper` translates between the progress DTOs and `PlayerProgress`, so `ProgressController` holds no translation code. `LevelDtoMapper` does the same for `LevelsController`: it builds the `UpdateLevelsRequest` from `LevelsDto`, keeps each section as it arrives, gives each `LevelDefinition` as a `LevelDto` of `docs/level-format.md`, and writes one error detail per level problem. An adapter is the border that receives the value of a value object: `../received.ts` holds the helpers `receiveValueOf()`, `receiveKeyOf()` and `receiveBoundsOf()`, which run one delivery and give what the receiver got. Imports `src/application` and `src/domain`; never `src/infrastructure`.
