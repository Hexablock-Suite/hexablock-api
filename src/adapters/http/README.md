# adapters/http

Nest controllers, request/response DTOs, `HttpErrorFilter` and `JwtAuthGuard` that translate HTTP to use cases. `JwtAuthGuard` calls the `AuthenticateToken` input port, never the `TokenIssuer` port. `ProgressDtoMapper` translates between the progress DTOs and `PlayerProgress`, so `ProgressController` holds no translation code. An adapter is the border that receives the value of a value object: `../received.ts` holds the helpers `receiveValueOf()`, `receiveKeyOf()` and `receiveBoundsOf()`, which run one delivery and give what the receiver got. Imports `src/application` and `src/domain`; never `src/infrastructure`.
