# adapters/http

Nest controllers, request/response DTOs, `HttpErrorFilter` and `JwtAuthGuard` that translate HTTP to use cases. `JwtAuthGuard` calls the `AuthenticateToken` input port, never the `TokenIssuer` port. `AuthDtoMapper` checks the shape of a sign-up or sign-in body, builds the `RegisterUserRequest` or the `LoginRequest` with their domain values, writes the rule messages and builds the token and user answers, so `AuthController` holds no translation code. A sign-in username that breaks its rule gets the 401 of a wrong password from the mapper. `ProgressDtoMapper` translates between the progress DTOs and `PlayerProgress`, and `toProblemDetails()` writes the text of each failed `Result` of the progress use cases, so `ProgressController` holds no translation code and only picks the status (#215). `LevelDtoMapper` does the same for `LevelsController`: it builds the `UpdateLevelsRequest` from `LevelsDto`, keeps each section as it arrives, gives each `LevelDefinition` as a `LevelDto` of `docs/level-format.md`, and writes one error detail per level problem. `LeaderboardDtoMapper` builds the request of `GetGlobalLeaderboard` and of `GetLevelLeaderboard` from the path turns each board into its DTO and writes the 404 text of `UnknownLevel` in `toProblemDetails()`, so `LeaderboardController` holds no translation code and narrows no union: each route calls its own input port (#218). `unauthorized.response.ts` holds `UNAUTHORIZED`, the OpenAPI 401 answer of a rejected token, which the four controllers share (#215). `progress-values.ts` builds the progress values of a body or a path, and it writes the 400 message of the code that a factory gives (decision 11), for `ProgressDtoMapper`, `LevelDtoMapper` and `LeaderboardDtoMapper`. An adapter is the border that receives the value of a value object: `../received.ts` holds the helpers `receiveValueOf()`, `receiveKeyOf()`, `receiveBoundsOf()` and `receiveBoundValuesOf()`, which run one delivery and give what the receiver got. `CredentialsDto` and `AuthDtoMapper` receive the numbers of the credential limits through `receiveBoundValuesOf()`. `CredentialsDto` writes the OpenAPI pattern of a username, and `Username.create()` checks the same rule in the domain (decision 17 of `docs/architecture/classes.md`). `SyncProgressDto` and `LevelDto` copy the patterns of `GameId` and `TopologyId` into the schema, and `test/unit/adapters/id-patterns-dto.spec.ts` checks that each copy accepts the same names as `GameId.of()` or `TopologyId.of()` (#214). Imports `src/application` and `src/domain`; never `src/infrastructure`; `@nestjs/*` only among packages (rule `http-adapters-import-only-nest`); and never `src/adapters/persistence` (rule `http-adapters-never-import-persistence`).
