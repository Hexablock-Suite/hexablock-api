# infrastructure

Layer 4: glue code only. Nest modules, the configuration in `auth/auth-config.ts` (the JWT secret, the level editors and the rate limit of sign-up and sign-in, #170) and the database connection in `database/`. No class here implements a port of `src/application`: the adapters of the ports, such as `SystemClock` in `src/adapters/clock` and `NestLogger` in `src/adapters/logging`, live in layer 3 (#212, option C). `AppModule` is the composition root: it binds each port of `src/application` to its adapter, for example `CLOCK` to `SystemClock`. It is the one file here that imports `src/application/ports` (rule `infrastructure-imports-no-port`). `src/main.ts` only starts it. May import every layer; no layer imports it except `src/main.ts`.
