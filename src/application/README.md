# application

Use cases and the ports they use. `ports/` holds the output ports that the outer layers implement, such as `ports/clock.ts`, which `SystemClock` in `src/infrastructure` implements, and `ports/progress-repository.ts`, which saves and finds the whole `PlayerProgress` aggregate. `use-case.ts` holds `UseCase<TRequest, TResponse>`, the contract that every input port binds. `aspects/` holds `UseCaseAspect`, the abstract Decorator of the use cases, and `LoggingAspect`, which writes each call to the `Logger` port in `ports/logger.ts` (Q12). `progress/` holds `SyncProgress` and `GetProgress`, and `auth/` holds the account use cases. A use case reads the instant from the `Clock` port and passes it to the domain. Imports only `src/domain`; no `@nestjs/*`, no adapters, no infrastructure.
